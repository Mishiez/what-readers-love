# what-readers-love
Exploring Goodreads data to uncover what drives reader engagement, book popularity, ratings, and author success.

## Data

This project uses the Goodreads dataset (dictionary, works, reviews).
CSVs are not committed (reviews.csv alone is ~880MB, over GitHub's limit).

To reproduce: download the dataset and place these files in `data/`:
- `goodreads_data_dictionary.csv`
- `goodreads_works.csv`
- `goodreads_reviews.csv`
